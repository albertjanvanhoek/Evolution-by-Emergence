# Functional Organization and the Velocity of the Ratchet

## A cost-geometric theory of retained capacity growth in networks

**Status:** working theory paper, draft 0.1  
**Framework:** Evolution by Emergence

### Abstract

A network can become more capable without adding many components. A novice and
an expert may possess roughly the same biological substrate while differing
radically in what transformations that substrate can reliably perform. An
ecosystem can contain similar amounts of matter while differing in niche
differentiation and the simultaneous functions generated by its interaction
network. This suggests that the quantity accumulated by an evolutionary
ratchet is not raw structure but **functional organization**: organization of a
commons into reliable, differentiated transformations.

We formalize this idea by separating organizational states from functional
targets. Let `s_t` denote the current organization of a network and let
`f` denote a functional target. We define `C_t^{\mathrm{perf}}(s_t,f)` as the declared cost
of reliably realizing `f` from `s_t`. The vector
`f ↦ C_t^{\mathrm{perf}}(s_t,f)` is the functional accessibility geometry of the
organization. It is the primitive moving object; no universal scalar complexity
measure is assumed.

For a matched time or resource interval, functional ratchet velocity is the
target-wise cost reduction

```math
v_t(f)=C_t^{\mathrm{perf}}(s_t,f)-C_{t+1}^{\mathrm{perf}}(s_{t+1},f).
```

A strong positive ratchet step preserves the cost of every declared retained
function while reducing the cost of at least one. We prove in Lean that such a
step necessarily creates a budget at which the functional repertoire strictly
expands. Ratchet acceleration is defined by comparing consecutive matched
velocity profiles: no declared target becomes slower and at least one improves
faster.

This formulation separates structure, causal function, and semantic
interpretation. It connects naturally to ecosystem multifunctionality,
functional diversity, neural functional repertoire, evolvability, and causal
emergence without identifying itself with any of them. Intelligent learning is
an inside specialization: knowledge, understanding, and skill are expressed as
reliable functional transformations, while learning-to-learn changes the
processes that determine the velocity with which further functional capacity is
acquired.

The resulting research question is not merely why cumulative organization is
possible, but what determines its speed:

> What controls the velocity at which a commons acquires retained functional
> organization?

---

## 1. The missing quantity in the ratchet

The central intuition behind cumulative evolution is familiar: retained
organization changes what can happen next. Yet this leaves open a quantitative
question.

What, exactly, is accumulating?

Raw component count is insufficient. A system can become substantially more
capable without a proportional increase in components. Edge count is also
insufficient: more connectivity can introduce redundancy, interference, or
loss of useful differentiation. Entropy and generic complexity measures capture
other properties but do not tell us which reliable transformations the system
can perform.

We propose that the relevant object is **functional organization**.

By functional organization we mean the organization of a shared substrate,
resource pool, or network -- a commons -- into differentiated and coordinated
relations that reliably realize transformations.

The term *function* is operational here. It does not require purpose or value.
A functional target is a declared transformation that can be tested.

Examples include:

- converting a sensory input into a reliable discrimination;
- converting an utterance into an appropriate linguistic response;
- converting resource flows into biomass production;
- cycling a nutrient through an ecological network;
- detecting and correcting a class of model error;
- manufacturing a component within specified tolerances.

The substrate and the function are different kinds of object. This is the first
formal separation.

## 2. Organization state and functional target

Let

```math
s_t\in\Sigma
```

be the organizational state of a network at time `t`.

Let

```math
f\in\Phi
```

be a functional target.

There is no requirement that `\Sigma=\Phi`. Indeed, in the applications
motivating this paper, that identification is usually conceptually wrong.

A neural state is not itself the function "understand this French sentence".
An ecological community state is not itself the function "recycle nitrogen".
An institution is not itself the function "detect a false claim".

Define

```math
C_t^{\mathrm{perf}}(s,f)
```

as the minimum declared **performance/evaluation cost** of reliably realizing
functional target `f` with the current organization `s`, under the relevant
environment and evaluation protocol.

Cost may represent execution time, energy, material, inference/processing
budget, coordination effort, communication burden, or error probability
transformed to a loss scale.

This is deliberately distinct from an **acquisition cost**

```math
C_t^{\mathrm{acq}}(s,f),
```

the resource required to reorganize or train `s` until it becomes capable of
`f`. Acquisition cost belongs to the earlier accessibility geometry. The
present paper asks what the organization can reliably do *now*. Without this
separation, a novice with a sufficiently large future training budget would
already count as possessing expert capability.

The primitive object is the profile

```math
\mathbf C_t
=
\left(C_t^{\mathrm{perf}}(s_t,f)\right)_{f\in\Phi}.
```

This profile is the **functional accessibility geometry**.

It is generally directed, target-dependent, and context-dependent.

### 2.1 Functional targets as operational tests

To keep *function* from becoming an observer's verbal label, a functional target
should be tied to a test specification.

Let a target `f` declare:

- a family or distribution of interventions/inputs `I_f`;
- an observable success criterion `S_f`;
- an allowed error level `\varepsilon_f`;
- the environmental/context conditions under which the test is meaningful.

At resource level `r`, organization `s` realizes `f` when, schematically,

```math
\Pr\left(
S_f
\mid
do(I_f),s,r
\right)
\ge
1-\varepsilon_f.
```

The functional cost can then be grounded as

```math
C_t(s,f)
=
\inf\left\{
r:
\Pr(S_f\mid do(I_f),s,r)
\ge 1-\varepsilon_f
\right\}.
```

This does not make the target family completely observer-independent: the
choice of intervention alphabet, scale, and success criterion is part of the
scientific question. But once declared, realization and cost are empirical
rather than semantic assertions.

For intelligent systems this distinction is crucial. An outside observer can
test whether a network reliably performs linguistic transformations without
claiming to read the network's experienced meaning directly from static
structure.

## 3. Functional repertoire

For budget `B`, define

```math
\mathcal F_t(B)
=
\{f\in\Phi:C_t^{\mathrm{perf}}(s_t,f)\le B\}.
```

This is the functional repertoire available within the declared budget.

A more organized commons need not possess more matter or more nodes. It may
instead support a larger, cheaper, more reliable, or more differentiated
functional repertoire.

This suggests a useful distinction:

```math
\boxed{
\text{amount of substrate}
\neq
\text{organization of substrate}
\neq
\text{functional repertoire}.
}
```

Structure constrains function, but function should not be assumed to be
readable uniquely from static structure alone.

## 4. The ratchet as retained change in functional geometry

Consider a transition

```math
s_t\rightarrow s_{t+1}.
```

The weakest second-order statement is that the functional geometry changes:

```math
\exists f:
C_{t+1}^{\mathrm{perf}}(s_{t+1},f)\neq C_t^{\mathrm{perf}}(s_t,f).
```

A directional opening requires only

```math
\exists f:
C_{t+1}^{\mathrm{perf}}(s_{t+1},f)<C_t^{\mathrm{perf}}(s_t,f).
```

This allows trade-offs: another function may become more expensive.

A strong retained improvement requires

```math
C_{t+1}^{\mathrm{perf}}(s_{t+1},f)\le C_t^{\mathrm{perf}}(s_t,f)
```

for every declared retained target, with strict inequality for at least one.

This is intentionally Pareto-like. It is stronger than adaptation in general
and should not be assumed for every evolutionary change.

The Lean formalization proves that any such strict improvement creates at least
one budget threshold `B` for which the later functional repertoire is a
strict superset of the earlier one.

Thus continuous cost improvement and binary repertoire expansion are connected
without being identified.

## 5. Ratchet velocity

The previous section describes a step. The central object of this paper is its
rate.

First define the signed functional gain over an interval:

```math
g_t(f)
=
C_t^{\mathrm{perf}}(s_t,f)-C_{t+1}^{\mathrm{perf}}(s_{t+1},f).
```

Positive `g_t(f)` means that functional target `f` has become cheaper.

If the interval has positive duration or declared resource width
`\Delta_t`, define normalized ratchet velocity

```math
v_t(f)
=
\frac{g_t(f)}{\Delta_t}.
```

For equal-duration unit steps, `g_t` and `v_t` differ only by the common
scale factor. Explicit normalization is required when comparing episodes with
different durations or resource windows.

A strong positive functional ratchet step satisfies

```math
g_t(f)\ge0
\quad\forall f\in\Phi_R
```

on the declared retained target family `\Phi_R`, with

```math
g_t(f^\star)>0
```

for at least one target.

The ratchet's velocity is therefore fundamentally **vector-valued**.

This matters. A single scalar can conceal a system that becomes dramatically
better at one function while losing another.

Applications may define a weighted scalar such as

```math
V_t
=
\int_{\Phi} w(f)v_t(f)\,d\mu(f),
```

or measure the change in the size of `\mathcal F_t(B)`, but the weights,
measure, target set, and budget are then substantive modelling choices rather
than universal facts.

## 6. Ratchet acceleration

The next question is whether the ratchet itself is speeding up.

Compare two matched intervals:

```math
s_0\rightarrow s_1\rightarrow s_2.
```

Define the normalized rates

```math
v_{01}(f)=\frac{C_0^{\mathrm{perf}}(s_0,f)-C_1^{\mathrm{perf}}(s_1,f)}{\Delta_{01}},
```

and

```math
v_{12}(f)=\frac{C_1^{\mathrm{perf}}(s_1,f)-C_2^{\mathrm{perf}}(s_2,f)}{\Delta_{12}}.
```

A strong acceleration condition is

```math
v_{12}(f)\ge v_{01}(f)
\quad\forall f\in\Phi_R,
```

with strict inequality for at least one target, while both intervals remain
positive retained ratchet steps.

This is not a claim of runaway acceleration.

Velocity can plateau or decline because of:

- resource scarcity;
- saturation of easy functional targets;
- increasing target difficulty;
- interference among retained functions;
- excessive rigidity;
- loss of diversity;
- coordination cost;
- environmental change;
- finite physical throughput.

The scientific problem is therefore to explain the sign and magnitude of

```math
\Delta v_t.
```

## 7. What controls velocity?

Let `\theta_t` denote parameters of the generative-maintenance system.

Candidate parameters include:

- resource throughput;
- variation or proposal rate;
- recombination rate;
- validation fidelity;
- retention strength;
- modularity and functional differentiation;
- interaction topology;
- delay between proposal and validation;
- repair rate after failed interaction;
- diversity of retained alternatives;
- cost of coordination;
- error-correction capacity.

Then schematically

```math
\mathbf v_t
=
F(\theta_t,s_t,E_t).
```

The next theory problem is not to assign a universally positive sign to each
parameter. It is to derive the regimes in which

```math
\frac{\partial v_t(f)}{\partial\theta_i}
```

is positive, negative, or changes sign.

This predicts phase structure rather than slogans such as "more diversity is
always better" or "more connectivity is always better".

### 7.1 A first velocity ledger

A useful intermediate representation separates the rate of potentially useful
events from the conditional conversion stages that turn such events into
retained functional gain.

For one declared scalar projection of the functional geometry, write

```math
v
=
\lambda\,
p_G\,
p_R\,
p_V\,
p_T\,
\bar g,
```

where:

- `\lambda` is opportunity rate;
- `p_G` is the conditional fraction generating a candidate;
- `p_R` is the conditional fraction that is resource-feasible;
- `p_V` is the conditional fraction that validates;
- `p_T` is the conditional fraction of validated changes that is retained;
- `\bar g` is mean retained functional gain per retained success.

If the fractions are conditional probabilities, the product is a chain-rule
factorization and does not require independence.

This equation is **not** asserted as a universal law of cumulative evolution.
It is a mechanism ledger. An application must justify that the observed
functional rate is represented by these stages.

Lean verifies the conditional implications of the ledger: with all other
factors held nonnegative and fixed, increasing opportunity, generation,
resource feasibility, validation, retention, or mean gain cannot lower the
ledger rate. A zero bottleneck at any required stage forces the corresponding
ledger rate to zero.

This distinction separates two questions:

```math
\boxed{
\text{What is ratchet velocity?}
}
```

from

```math
\boxed{
\text{What mechanisms determine its ledger coordinates?}
}
```

The first is supplied by the functional cost geometry. The second is the next
domain-specific research programme.

## 8. Ecology as an outside test domain

Ecology provides a natural test because ecosystems are networks whose
components can differentiate into roles and jointly support multiple functions.

The relevant comparison is not simply species count.

Ecological work on functional diversity asks how species traits and roles shape
ecosystem processes. Work on ecosystem multifunctionality asks how ecosystems
simultaneously sustain multiple functions.

These literatures already show why scalarization is delicate: which functions
are selected, how they are normalized, and how trade-offs are aggregated all
matter.

The present framework therefore treats an ecosystem as inducing a cost profile
over functional targets.

Examples might include the resource or perturbation cost required to preserve
declared levels of:

- primary production;
- decomposition;
- nutrient cycling;
- pollination;
- carbon retention;
- recovery after disturbance.

The hypothesis is not that ecological succession always increases all of these.
Rather, ecological organization traces a trajectory through functional
geometry, and the retained ratchet question concerns when and how that
trajectory creates cheaper or newly realizable combinations of function.

## 9. Neural systems and expertise

Skill learning provides an especially intuitive example of the
structure/function separation.

A person learning a language does not acquire a new brain in proportion to the
new capability. Instead the existing biological network changes its
organization, representations, connectivity, and dynamics.

The relevant gain is functional.

A beginner and an expert may differ in the reliability, speed, flexibility,
context range, and energetic or attentional cost with which many related
transformations are performed.

The functional target space for language can include mappings such as:

```math
\text{sound}\rightarrow\text{phoneme},
```

```math
\text{utterance}\rightarrow\text{meaning},
```

```math
\text{meaning}\rightarrow\text{context-appropriate response}.
```

Expertise changes a family of such transformations, not merely one benchmark
score.

This is compatible with neuroscience work showing structural and functional
reorganization with expertise and with network models in which structural
architecture supports a repertoire of possible functional configurations.

## 10. Structure, causal function, and meaning

The framework distinguishes three descriptions.

### 10.1 Structure

```math
N_t
```

describes components and relations.

### 10.2 Causal-functional repertoire

```math
\Phi(N_t)
```

describes the reliable transformations supported by that organization under
declared interventions and environments.

### 10.3 Semantic or experienced capability

For an intelligent system, some functional transformations are represented
internally as knowledge, concepts, expectations, meanings, skills, and goals.

Call this internal description `K_t`.

Schematically:

```math
N_t
\longrightarrow
\Phi(N_t)
\longleftrightarrow
K_t.
```

The first relation is causal/operational.

The second is not assumed to be a one-to-one decoding relation. A complete
semantic description need not be recoverable from static structural
observation.

Function can nevertheless be probed from outside through perturbation,
counterfactual testing, and performance across environments.

This avoids requiring privileged introspection while preserving the distinction
between physical organization and what that organization can do.

## 11. Intelligent networks: the inside specialization

For an intelligent network, the functional targets may be learning and
reasoning capabilities.

The companion learning-maintenance framework introduces an internal process
state `P_t` containing mechanisms for search, listening, faithful signalling,
uncertainty exposure, testing, revision, edge maintenance, repair,
re-engagement, retention, and recombination.

Those processes alter the future functional cost geometry.

Ordinary learning changes current capability.

Learning-to-learn changes the process controlling the rate at which further
capabilities become available.

For matched held-out learning episodes, define learning velocity by the
functional cost reduction achieved per unit time/resource.

Then an endogenous change to `P_t` is a genuine process-level
self-improvement only if it improves held-out functional acquisition while
preserving required prior function.

The stronger recursive claim is:

```math
\boxed{
\text{the self-generated process change increases future learning velocity}.
}
```

This gives the previously abstract improvement-productivity quantity a direct
operational interpretation.

It also imposes an important experimental requirement: recursive improvement
must be evaluated under matched starting conditions, target distributions, and
resource windows. Faster apparent learning on easier later tasks is not
acceleration of the ratchet.

## 12. Relation to neighboring theories

### 12.1 Ecosystem multifunctionality

This literature already treats ecosystems as simultaneously realizing multiple
functions and has developed several competing aggregation methods.

The present framework uses this as an antecedent, not as a novelty claim.

Its distinct move is to treat the cost profile of functional realization and
its retained rate of change as the primitive object.

### 12.2 Functional repertoire in neuroscience

Network neuroscience has used functional repertoire to describe the diverse
functional configurations supported by structural architecture.

The present framework generalizes the repertoire concept by attaching
operational resource cost and retained velocity to declared functional targets.

### 12.3 Evolvability

Evolvability theory already studies how current biological organization changes
the distribution of future adaptive variation.

The present framework should therefore not claim priority for second-order
adaptive capacity.

Its proposed contribution is a cross-domain functional cost geometry and an
explicit rate variable over retained functional change.

### 12.4 Causal emergence

Effective-information approaches quantify the selectivity and determinism of
causal structure and can identify macro scales with stronger causal
descriptions than their micro descriptions.

This is close in spirit but measures a different object.

Functional ratchet velocity is target-conditioned and resource-sensitive. It
asks how cheaply declared transformations can be reliably realized and how that
profile changes through retained organization.

## 13. Falsifiable programme

The framework suggests several direct tests.

### H1 -- Structure/function non-equivalence

Networks with similar component count or coarse structural statistics can have
substantially different functional cost profiles.

### H2 -- Functional ratchet

Some retained organizational changes strictly reduce the cost of at least one
held-out function while preserving declared prior functions.

### H3 -- Trade-off prevalence

Many adaptive changes are directional openings rather than global
Pareto-improvements: some functional costs fall while others rise.

### H4 -- Parameter-dependent velocity

The effect of diversity, connectivity, recombination, retention, validation,
resources, and delay on functional ratchet velocity changes sign across
regimes.

### H5 -- Matched acceleration

Some trajectories exhibit a later matched interval whose functional velocity
profile dominates an earlier interval.

### H6 -- Intelligent process acceleration

Some endogenous modifications to a learning-maintenance process increase
held-out functional acquisition velocity under matched resource conditions.

A failure of these hypotheses would constrain or falsify corresponding parts of
the programme.

## 14. Formal status

The first formal layer is implemented in:

`formalization/cumulative-accessibility/CumulativeAccessibility/FunctionalRatchetVelocity.lean`

It separates organization states from functional targets and machine-checks the
relationship between strict functional cost reduction, positive ratchet
velocity, and thresholded functional repertoire expansion.

It also defines a strong matched-step acceleration relation and provides a
minimal two-state/two-function witness.

The formalism does not define a universal scalar amount of organization.

That omission is deliberate.

---

## 15. Conclusion

The central claim of this paper is a change of object.

The ratchet does not have to be described as the accumulation of more matter,
more nodes, more edges, or an unspecified scalar complexity.

It can instead be described as retained change in the **functional
accessibility geometry** of an organized commons.

The organization is the substrate.

The functional repertoire is what that organization can reliably do.

The cost profile records how accessible those functions are.

The ratchet velocity records how fast that profile improves.

The acceleration records whether the process of acquiring retained functional
organization is itself becoming faster.

This yields a common outside language for biological, ecological, neural,
social, and technological systems while leaving their mechanisms distinct.

It also exposes the next quantitative problem for Evolution by Emergence:

```math
\boxed{
\text{derive ratchet velocity from generation, retention, validation,
resources, interaction structure, and delay.}
}
```

That is the point at which a theory of cumulative organization becomes a theory
of its speed.
