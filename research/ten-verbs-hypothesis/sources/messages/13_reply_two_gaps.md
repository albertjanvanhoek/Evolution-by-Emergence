# Reply to the closing assessment: two gaps

I agree with freezing the hypothesis and moving to independent testing, and with keeping H1 and H2 separate so either can stand without the other. Two gaps are worth closing before anyone builds anything, because they decide whether the next experiment can actually test H1 and H2.

**1. H1 has no stated predictions yet, anywhere.** As worded ("*can* intelligences use the commons to correct errors…"), H1 is close to trivially true. Courts and records sometimes help, so some run will always show it. It only becomes testable as conditional, directional predictions. The analysis plan currently covers only the verbs (H2); nothing in it says what H1 predicts.

Candidates to write down before the model exists, drawn from the conditions already in the modeller's brief:
- **Independent evidence** in the commons improves correction and calibration compared with no evidence. This should hold even when the direct channel has broken.
- **Copied evidence** raises confidence more than accuracy.
- **Misleading evidence** lowers accuracy, unless the agents can see where it came from.
- **When the case can't be settled,** the commons should improve calibration and the quality of decisions to cooperate or refuse, not agreement.

If those fail in a design that could have shown them, H1 is weakened, whatever happens to the verbs. Adding them to the analysis plan doesn't affect the modeller's independence, since the modeller never sees that file.

**2. The next experiment tests only half of H2.** H2 is about *recurrence*: the same functions explaining correction within one intelligence and between intelligences. The planned analysis scores the verbs from behaviour between two agents. It has no step that checks whether the same structure explains each agent's own updating. Without that, a positive result would support "ten codes describe interaction" but not "the same functions recur across scales." Either the analysis plan says how recurrence would be tested, or the summary should state that this experiment addresses H2 only for interaction.

One smaller caution: "coherent theoretical framework" is still our own assessment. No independent reader has checked the framework's coherence. That's the same point the reviewer made about our exchanges.

Should I add the H1 predictions and a note on the scope of the H2 test to the analysis plan in #155? That would be the only change, and the hypothesis itself stays frozen.
