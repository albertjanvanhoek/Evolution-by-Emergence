# Bridge: Retained Organization and the Learning Constitution

> **Status:** conceptual integration note between the retained-organization programme in PR63 and the v18 Learning Constitution.
>
> This note does not merge the two theorem surfaces. It states how the v18 agent/interdependence layer can be represented as an intelligent-network specialization of the broader retained-organization architecture.

## 1. The nesting of levels

The relationship is:

[
oxed{
	ext{EbE retained-organization layer}
supset
	ext{intelligent-agent network}
supset
	ext{Learning Constitution / SCAP specialization}.
}
]

The universal layer studies retained relational organization and its effect on future transition/accessibility structure.

The intelligent-network layer fixes a scale:

- nodes are learning agents;
- edges are channels through which information, criticism, evidence, coordination, and repair can occur;
- node states contain partial internal models;
- edge states affect the practical accessibility of later correction.

The Learning Constitution then places conditions on the transition architecture of that intelligent network so that current decisions do not make future correction structurally impossible.

This is a specialization, not an assertion that every physical EbE system contains beliefs, challenges, appeals, or moral agents.

## 4. Binary correctability is a boundary case of graded accessibility

The v18 formalization is mainly qualitative:

[
	ext{a corrective route exists}
quad	ext{or}quad
	ext{it does not}.
]

PR63 generalizes this by asking how accessible such a route is under finite time, resource, attention, or procedural budgets.

Let

[
C_{mathrm{corr},t}(S,a)
]

be a declared cost of obtaining an effective correction route for affected agent (a) from shared state (S).

Equivalently use graded accessibility

[
mathcal A_T(mathrm{corr}mid S,a,B).
]

A self-sealing restriction in the v18 sense removes challenge or revision of the restriction itself. In a cost specialization, this corresponds to the limiting case

[
C_{mathrm{corr}}=infty,
]

or, for the declared finite horizon/budget,

[
mathcal A_T(mathrm{corr})=0.
]

Therefore:

[
oxed{
	ext{v18 blocks the zero-accessibility / infinite-viscosity boundary case of correction}.
}
]

This does **not** mean every large finite correction cost violates v18. It means PR63 supplies a graded interior that v18 did not quantify.

A process can retain a formally available appeal while making it extremely slow, expensive, risky, or practically unusable. That case is visible in the graded accessibility framework even when binary reachability remains true.

## 5. SCAP as a paid maintenance protocol in the graded interior

SCAP is not added to the universal EbE theorem as a moral law.

It is a candidate maintenance protocol for an intelligent network whose edge/process architecture must itself persist.

Write

[
R_t^{mathrm{SCAP}}
subseteq R_t
]

for retained protocol structure and

[
M(R_t^{mathrm{SCAP}})>0
]

for its maintenance, monitoring, training, review, repair, redundancy, or coordination burden.

Candidate SCAP functions map naturally onto network variables:

| SCAP function | Candidate network effect |
| --- | --- |
| signal fidelity | reduce corruption of task-relevant information |
| corrigibility | preserve usable routes by which evidence can alter models/actions |
| useful diversity | prevent premature collapse of independent information/candidates |
| redundancy | maintain alternative correction paths |
| repair / conditional forgiveness | reduce persistent viscosity after reparable edge failure |
| reciprocity / accountability | close return loops that fund useful edge maintenance |
| observability | expose degradation before visible network failure |
| education / transmission | reproduce the correction architecture across agents/generations |
| SCAP corrigibility | keep the maintenance protocol itself revisable |

Under PR63, SCAP receives no exemption from the paid-retention test.

Its retained structure can be beneficial, neutral, burdensome, or lock-in.

The appropriate empirical question is whether, after its own costs are counted,

[
mathcal A_T(Ymid R^{mathrm{SCAP}},B-M(R^{mathrm{SCAP}}))
]

improves for declared future learning/correction targets relative to a matched alternative.

The reflexive SCAP clause—keep SCAP corrigible—is therefore structurally important: retained maintenance infrastructure can itself become a high-viscosity constraint.

## 6. Learning verbs as mechanisms acting on accessibility and velocity

The v18 Learning Constitution formalizes process verbs such as challenge, present evidence, revise, reopen, repair, appeal exclusion, and restore access.

The wider intelligent-learning work also uses verbs such as seek, listen, signal faithfully, expose uncertainty, test, maintain disagreement, retain, and recombine.

These verbs are **inside descriptions**. They do not receive universal positive signs.

An application-specific bridge

[
Gamma:
P_tlongrightarrow C_t
]

maps learning-maintenance process state (P_t) to the outside accessibility/cost geometry.

Candidate hypotheses include:

| Learning-maintenance process | Candidate rate/accessibility effect |
| --- | --- |
| seek / encounter | increase opportunity rate (lambda) or reduce opportunity wait (K) |
| listen | increase probability that informative evidence enters the usable pipeline |
| signal faithfully | reduce signal corruption and verification burden |
| expose uncertainty | increase detectability of potentially corrective discrepancy |
| test | improve validation while consuming time/resources |
| revise | reduce validated-response lag (Delta) |
| maintain disagreement | preserve alternative candidates for later testing |
| maintain edge | prevent loss of future correction opportunities |
| repair | lower viscosity of a damaged but still valuable edge |
| re-engage | restore opportunities after demonstrated repair |
| retain | increase persistence of validated improvement |
| recombine | alter candidate generation and retained-gain distribution |

The existing reduced rate ledger is

[

]

The existing bounded-rate certificate uses opportunity wait (K), response lag (Delta), and minimum retained gain (g_{min}):

[

Therefore a learning verb can affect discovery/learning speed when a domain-specific model or experiment establishes that the verb changes one or more of these coordinates.

The framework does **not** assert, for example,

[

More search can starve validation; more testing can increase delay; more openness can admit noise; more stability can protect function while increasing justified revision cost.

The target is selective, retained learning capacity rather than maximal openness.

## 8. Non-claims

This bridge does not establish that:

- all EbE systems are intelligent-agent networks;
- forced free will is a theorem about metaphysical free will;
- the Learning Constitution is uniquely necessary or sufficient for learning;
- every finite correction cost should be minimized;
- SCAP is uniquely correct or universally beneficial;
- every learning verb improves accessibility or velocity;
- corrigibility guarantees truth;
- maximal openness is optimal;
- preserving every edge is desirable;
- legal or moral obligations follow from the retained-organization formalism.

The bridge is a compatibility and operationalization claim.

Its empirical content begins when a domain supplies measurable mappings from retained procedures and learning-maintenance processes to graded accessibility, cost, delay, validation, retention, and later unvisited targets.
