# Theorem Notes

> **Status:** candidate mathematics for the retained-organization programme.  
> These results are specializations of the EbE centre, not the centre itself.

The governing interpretation is:

> **Retained organization becomes causal structure for future change.**

The results below ask when that statement is non-trivial: retention is paid for, it must transfer to later/unvisited organization, and reusable hierarchy must be generated by an explicit sharing mechanism rather than by free parameters.

---

## 1. Paid retention and the transfer test

Let \(s\) be a current state and \(X\) a candidate organization produced endogenously.

Define two counterfactual successor states:

\[
s^+=\operatorname{Retain}(s,X),
\qquad
s^-=\operatorname{Lose}(s,X).
\]

Let \(R^-\) be the baseline retained repertoire and \(R^+=R^-\cup\{X\}\). Let

\[
M(R)\ge0
\]

be the total declared keeping/storage/reconstruction burden, and define the marginal burden

\[
\boxed{
\mu_R(X)=M(R^+)-M(R^-)\ge0.
}
\tag{T0}
\]

Both counterfactuals must start from the same gross resource budget \(B^{\mathrm{gross}}\). Their free budgets are therefore

\[
B^- = B^{\mathrm{gross}}-M(R^-),
\qquad
B^+ = B^{\mathrm{gross}}-M(R^+)
     = B^- - \mu_R(X).
\]

Let \(\mathcal H_t\) denote the set of organizations already visited by time \(t\).

For a graded finite-horizon accessibility measure \(\mathcal A_T\), define the transfer gain to an **unvisited** target \(Y\notin\mathcal H_t\):

\[
\boxed{
\Delta^{\mathrm{tr}}_{T}(X;Y)
=
\mathcal A_T\!\left(Y\mid s^+,B^+\right)
-
\mathcal A_T\!\left(Y\mid s^-,B^-\right).
}
\tag{T1}
\]

Equivalently, if \(B\) denotes the free budget after the upkeep common to both arms, then

\[
\Delta^{\mathrm{tr}}_{T}(X;Y)
=
\mathcal A_T\!\left(Y\mid s^+,B-\mu_R(X)\right)
-
\mathcal A_T\!\left(Y\mid s^-,B\right).
\]

Retention transfers when

\[
\boxed{
\exists\,Y\notin\mathcal H_t:
\Delta^{\mathrm{tr}}_{T}(X;Y)>0.
}
\tag{T2}
\]

This is intentionally stronger than ordinary state dependence.

A state can change its immediate successor without generating transfer. The transfer test asks whether **paid retained history improves graded access to organization not already visited**.

### Cost specialization

If accessibility is represented by a lower-is-better route/use cost, let \(K_{s^+}^{\mathrm{run}}(Y)\) explicitly **exclude** the keeping cost already represented by \(\mu_R(X)\). Define

\[
\boxed{
\Delta^{\mathrm{tr}}_{K}(X;Y)
=
K_{s^-}(Y)
-
\left[\mu_R(X)+K_{s^+}^{\mathrm{run}}(Y)\right].
}
\tag{T3}
\]

Positive transfer requires

\[
\boxed{
\mu_R(X)+K_{s^+}^{\mathrm{run}}(Y)
<
K_{s^-}(Y).
}
\tag{T4}
\]

This is the same ledger as the accessibility form, not an additional charge. If a domain-specific \(K\) already includes retention/upkeep, \(\mu_R(X)\) must not be added again.

This can fail. Retention can be neutral or burdensome.

## 2. Retention is not ordinary state dependence

For the current programme, call \(X\) a **retained organizational memory** only when the application identifies all five properties below.

1. **Endogenous** — \(X\) is produced by the system's own generative/reorganizational dynamics rather than inserted as a fixed external parameter.
2. **Slow** — \(X\) persists or remains reconstructibly available beyond the fast event that created it, on a declared separation of time scales.
3. **Paid** — maintenance, storage, reconstruction, protected capacity, or another finite burden is explicitly accounted for.
4. **Reused** — a later transition causally depends on \(X\), established by an ablation/counterfactual or equivalent mechanism.
5. **Transferable** — the effect of \(X\) changes graded accessibility for a later context, episode, descendant, task, or unvisited organization rather than only continuing the same instantaneous state.

These criteria operationalize the distinction requested by falsification target #4.

They are not asserted to be the only possible definition of memory, but without comparable criteria the operator \(\mathcal K[G]\) is too unconstrained to distinguish EbE from generic state-dependent dynamics.

## 3. General paid-retention identity

Let \(R\) be the current retained repertoire.

Separate:

\[
K_R(Y)
=
\text{future construction/use burden of target }Y\text{ given }R
\]

from

\[
M(R)
=
\text{maintenance/storage/reconstruction burden of keeping }R.
\]

For future target distribution \(P\), define

\[
\mathcal J(R)
=
\mathbb E_{Y\sim P}[K_R(Y)]
+
M(R).
\tag{R1}
\]

For candidate \(X\), define expected future saving

\[
S_R(X)
=
\mathbb E\!\left[K_R(Y)-K_{R\cup\{X\}}(Y)\right]
\]

and marginal upkeep

\[
\Delta M_R(X)
=
M(R\cup\{X\})-M(R).
\]

Then exactly:

\[
\boxed{
\mathcal J(R\cup\{X\})-\mathcal J(R)
=
\Delta M_R(X)-S_R(X).
}
\tag{R2}
\]

Hence:

\[
\boxed{
\mathcal J(R\cup\{X\})<\mathcal J(R)
\iff
S_R(X)>\Delta M_R(X).
}
\tag{R3}
\]

This is elementary bookkeeping, not a novelty claim.

Its role is to make one point non-negotiable:

\[
\boxed{
\text{retention is not free.}
}
\]

## 4. Repetition threshold for a reusable scaffold

Consider a suborganization \(A\) that appears \(n\) times in later construction.

Let:

- \(c>0\): cost to inline/reconstruct one occurrence of \(A\);
- \(r\ge0\): cost to reference/reuse retained \(A\);
- \(h\ge0\): one-time definition/retention/upkeep burden;
- \(c>r\).

Without retention:

\[
K_{\mathrm{inline}}=nc.
\]

With retention:

\[
K_{\mathrm{retain}}=c+h+nr.
\]

Retention is strictly beneficial iff

\[
nc>c+h+nr,
\]

equivalently

\[
\boxed{
(n-1)c>nr+h.
}
\tag{Rep1}
\]

Or:

\[
\boxed{
n>
\frac{c+h}{c-r}.
}
\tag{Rep2}
\]

The minimum integer repetition count is therefore

\[
\boxed{
n^\star
=
\left\lfloor
\frac{c+h}{c-r}
\right\rfloor+1.
}
\tag{Rep3}
\]

### Single-use no-go

If \(n=1\), then the saving condition becomes

\[
0>r+h,
\]

which is impossible for nonnegative \(r,h\).

Therefore:

\[
\boxed{
\text{a purely representational scaffold cannot pay for itself from a single additive occurrence.}
}
\tag{Rep4}
\]

A pure scaffold requires repeated/shared use, direct use, or an explicitly non-additive mechanism.

This corrects the earlier free-parameter scaffold formulation.

## 5. Chain dichotomy

Consider a nested chain

\[
A_1\prec A_2\prec\cdots\prec A_k.
\]

Suppose the only value of an interior \(A_i\) is representational: it is not directly demanded as a target.

### Non-repeating chain

If every parent contains exactly one occurrence of its child,

\[
n_i=1
\qquad
\forall i<k,
\]

and reference/upkeep costs are nonnegative, then no interior module can be justified purely by additive representation saving:

\[
\boxed{
n_i=1
\Longrightarrow
\text{no pure representational scaffold at level }i.
}
\tag{CD1}
\]

### Repeating chain

If each level has genuine repeated/shared use and satisfies

\[
\boxed{
(n_i-1)c_i>n_ir_i+h_i,
}
\tag{CD2}
\]

then retaining the level reduces the declared representation/construction objective.

Thus the additive model has a sharp qualitative dichotomy:

\[
\boxed{
\text{single-use nesting does not generate hidden hierarchy;}
\quad
\text{repeated/shared nesting can.}
}
\tag{CD3}
\]

This is the theoretical counterpart of the simulation control in which destroying cross-task shared substructure largely removed hierarchy.

## 6. Repetition-depth theorem

To make the arbitrary-depth claim robust, use a laminar nested construction.

For \(i=1,\ldots,k-1\), the retained definition of \(A_{i+1}\) contains \(n_i\) occurrences of \(A_i\). The top organization \(A_k\) occurs \(n_k\) times in the external workload.

For any retained dictionary \(D\) that does not yet contain \(A_i\), let:

- \(N_i(D)\): the number of occurrences of \(A_i\) that must be represented before adding \(A_i\);
- \(c_i(D)\): the inline/reconstruction cost per occurrence under the lower-level choices in \(D\);
- \(r_i\ge0\): reference cost;
- \(h_i\ge0\): definition/retention/upkeep burden.

Assume additive laminar accounting, no alternative substitution that bypasses the declared occurrence structure, and bounds

\[
N_i(D)\ge n_i\ge2,
\qquad
c_i(D)\ge c_i^{\min}>r_i
\]

for every admissible \(D\) not containing \(A_i\).

Adding \(A_i\) changes the declared objective by

\[
\begin{aligned}
F(D\cup\{A_i\})-F(D)
&=
c_i(D)+h_i+N_i(D)r_i-N_i(D)c_i(D)\\
&=
h_i+N_i(D)r_i-(N_i(D)-1)c_i(D).
\end{aligned}
\tag{RD0}
\]

Now define the saving function

\[
g_i(N,c)=(N-1)c-Nr_i-h_i.
\]

For \(c>r_i\), \(g_i\) is increasing in \(N\); for \(N\ge2\), it is increasing in \(c\). Therefore its worst admissible case is \((N,c)=(n_i,c_i^{\min})\).

If, for every level,

\[
\boxed{
(n_i-1)c_i^{\min}
>
n_ir_i+h_i,
}
\tag{RD1}
\]

then \(F(D\cup\{A_i\})<F(D)\) for **every** admissible dictionary \(D\) lacking \(A_i\).

Hence any candidate optimum that omits a level can be strictly improved by adding that level. Every global optimum must therefore retain the full declared chain:

\[
\boxed{
A_1\prec A_2\prec\cdots\prec A_k.
}
\tag{RD2}
\]

Equivalently:

\[
\boxed{
n_i
>
\frac{c_i^{\min}+h_i}
{c_i^{\min}-r_i}
\quad
\forall i.
}
\tag{RD3}
\]

So arbitrary retained depth is possible for arbitrary prescribed \(k\), but only when every level clears a paid repetition threshold.

This is a **sufficient theorem for the declared additive laminar model**, not a universal law of hierarchy. The finite script checks the threshold algebra and the worst-case marginal-improvement logic; it is not a proof assistant result.

## 7. Why the earlier free-\(H_i\) scaffold theorem was too weak

A coarse pairwise objective can write a generic downstream saving \(H_i\) and conclude that a scaffold is retained when

\[
H_i>m_i.
\]

The algebra is valid as bookkeeping, but it does not explain where \(H_i\) comes from.

If \(H_i\) is left free, the model can simply assume the hierarchy it claims to explain.

For the current programme, a scaffold mechanism therefore needs to be derived from one of:

- repeated/shared substructure;
- direct reuse;
- non-additive physical synergy;
- catalytic acceleration;
- error reduction/reliability gain;
- another explicit mechanistic source.

The repetition theorem supplies one such mechanism.

## 8. Law D — emergence-to-retention feedback (candidate)

The retained-organization centre does not require every update to be strictly emergent.

But for a theory called *Evolution by Emergence*, the role of emergence should be explicit.

Let candidate organization \(X\) realize a strict whole-level capability:

\[
E(X,\phi,c).
\]

Let the capability alter the resource ledger by

\[
\Delta L_\phi
=
\Delta I_\phi-\Delta C^{\mathrm{op}}_\phi,
\]

where \(\Delta I_\phi\) is the capability's contribution to captured/useful throughput and \(\Delta C^{\mathrm{op}}_\phi\) is its incremental operating/expression burden **excluding** the marginal retention burden \(\mu_R(X)\).

A candidate **Law D feedback condition** is:

\[
\boxed{
E(X,\phi,c)
\land
\Delta L_\phi\ge\mu_R(X)
\Longrightarrow
\text{the emergent capability can pay for its own declared marginal retention burden.}
}
\tag{D1}
\]

If a domain-specific operating-cost term already includes retention upkeep, that upkeep is not added a second time.

If \(\Delta L_\phi>\mu_R(X)\) and exploration/reorganization intensity is nondecreasing in post-maintenance slack, then the retained emergent organization can also raise future search budget.

A second, independent emergence route is **essential reuse**:

if retained \(X\) is an essential parent/constraint for an unvisited target \(Y\) and raises its graded accessibility,

\[
E(X,\phi,c)
\land
\Delta_T^{\mathrm{tr}}(X;Y)>0,
\]

then the emergent product has become part of later transition machinery.

These are candidate bridges, not yet universal theorems.

Their purpose is to keep the question open and explicit:

\[
\boxed{
\text{when does emergent function feed back into the conditions of later emergence?}
\]

## 9. Upkeep bound

Let gross available budget at time \(t\) be \(B_t^{\mathrm{gross}}\).

If retained modules \(X_i\) require upkeep \(\mu_i>0\), then free response/construction budget is

\[
\boxed{
B_t^{\mathrm{free}}
=
B_t^{\mathrm{gross}}
-
\sum_{i\in R_t}\mu_i.
}
\tag{U1}
\]

Therefore any retained repertoire must satisfy the solvency condition

\[
\boxed{
\sum_{i\in R_t}\mu_i
\le
B_t^{\mathrm{gross}}
}
\tag{U2}
\]

to leave nonnegative free budget.

If

\[
\mu_i\ge\mu_{\min}>0
\]

and gross budget is finite, then active retained capacity is bounded:

\[
\boxed{
|R_t|
\le
\left\lfloor
\frac{B_t^{\mathrm{gross}}}{\mu_{\min}}
\right\rfloor.
}
\tag{U3}
\]

Open-ended historical accumulation therefore requires turnover, reconstruction, compressed representation, growing resources, vanishing marginal upkeep, externalized memory, or another explicit relaxation.

This is consistent with the repository's active/history distinction: unbounded history does not imply unbounded simultaneously active retained structure.

## 11. Next theorem target

The previous target—

> when does any retained change alter \(\mathcal K\)?

—is too weak. Generic state-dependent dynamics can satisfy it trivially.

The informative next target is the **paid transfer theorem**:

> **Under a graded accessibility measure, paid retention, and a declared counterfactual ablation, derive sufficient and/or necessary conditions under which an endogenously retained organization raises the probability or lowers the net cost of reaching at least one organization not previously visited.**

In accessibility form:

\[
\boxed{
\exists Y\notin\mathcal H_t:
\mathcal A_T(Y\mid s^+,B^+)
>
\mathcal A_T(Y\mid s^-,B^-),
}
\tag{NT1}
\]

with \(B^\pm=B^{\mathrm{gross}}-M(R^\pm)\).

In cost form:

\[
\boxed{
\exists Y\notin\mathcal H_t:
\mu_R(X)+K^{\mathrm{run}}_{s^+}(Y)
<
K_{s^-}(Y).
}
\tag{NT2}
\]

Here \(K^{\mathrm{run}}\) excludes the retention/upkeep amount already represented by \(\mu_R(X)\).

This test can fail.

That failure is scientifically useful: it distinguishes retained causal structure from ordinary history dependence and from burdensome retention.
